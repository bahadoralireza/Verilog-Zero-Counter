# Zero Counter in Verilog HDL

This repository contains my solution for **Computer Assignment 1-2** of the **Digital Logic Design** course at the University of Tehran.

The assignment focuses on designing and implementing Zero Counter (ZC) circuits using different abstraction levels in Verilog HDL, and comparing their functionality and timing characteristics.

## Project Parts

### Part 1
Design a **3-input Zero Counter (3-input ZC)** using CMOS switch-level logic with minimum transistor count and specified transistor delays.

### Part 2
Implement the 3-input Zero Counter using Verilog switch-level modeling and verify its functionality with a testbench.

### Part 3
Implement the same circuit using Verilog gate primitives and compare its timing with the transistor-level implementation.

### Part 4
Implement the Zero Counter using continuous assignment (`assign`) statements and compare the results with previous implementations.

### Part 5
Construct a **7-input Zero Counter** structurally using multiple instances of the 3-input Zero Counter.

### Part 6
Implement the 7-input Zero Counter using the assign-based modules and compare the timing with Part 5.

### Part 7
Design a **15-input Zero Counter** hierarchically using the 7-input and 3-input Zero Counter modules and evaluate the worst-case propagation delay.
